## 💡 为什么传统网格常常“赚小钱、亏大钱”？

普通券商自带的单轨等额网格，在 A 股复杂牛熊震荡中存在四大致命死穴：

| 市场极端场景 | 传统券商网格表现 | ETF Grid Pro 的量化解法与优势 |
| :--- | :--- | :--- |
| 🚀 **单边大牛市** | 涨几格筹码便被快速卖光，**彻底踏空主升浪** | **【模式 B 智能利润池滚存留股】**：差价利润不留现金，每攒满 100 股自动沉淀为永久免费份额，0 成本坐享长牛数倍主升浪。 |
| 📉 **单边深幅暴跌** | 高位等额买入打光子弹，**深水区钝化装死** | **【三轨复合 + 倒金字塔加码 + 小网熔断】**：大中小轨分兵防守，底部筹码加倍重仓低吸，小网 5 格严格熔断，防守弹药充足。 |
| 🌪️ **选错震荡标的** | 选了无波动的死水或单边衰退品种，越网越亏 | **【4 维量化体检】**：严把波动率、ADX 震荡度与流动性红线，振幅不足或流动性极差时一票否决。 |
| 🧮 **回测虚假繁荣** | 忽略 A 股 T+1、碎股取整与单笔最低 5 元佣金 | **【基于 GridSlot 状态机的真实账本】**：严格模拟 A 股隔夜可用持仓解冻、万 1 最低 0.2 元真实券商摩擦与真实资金账本，杜绝账面自欺。 |

## 🧭 实盘决策五步闭环

无需复杂的配置摸索，遵循 5 步即可完成从“标的体检”到“券商条件单实盘”的完整闭环：

```
① 选标的 ──────▶ ② 定参数 ──────▶ ③ 测极限 ──────▶ ④ 验回测 ──────▶ ⑤ 抄挂单
 4 维体检排除陷阱  选 ATR/经典步长   滑块模拟 -60%   5 年跨牛熊验证   一键复制多轨阶梯
 不提供估值判断    指定持仓成本锚点   查看资金水淹线   三色彩虹利润归因  直接录入券商APP
```

1. **第 1 步：查标的（量化体检）**
   - 在首页「全市场做 T 核心 ETF 选品雷达」点选标的，代码会填入下方「手动精确输入 ETF 代码」；也可直接手输 6 位代码；
   - 选品宇宙只有 11 个可购赛道：科技芯片、新能源制造、医药健康、大金融、大消费、周期资源、公用红利、国防军工、跨境全球、大宗商品、核心宽基。「全部」等于这 11 个赛道之和。无法归入这些赛道的标的记为未归类，不进入选品，也不进入适合度榜。不要把「其他主题」当成可购赛道或现行入口；
   - 查看 4 维量化体检评分（振幅空间、年化波动率 15%~45% 黄金区间、ADX < 20 震荡判据、流动性防御）；
   - 系统不计算也不展示估值百分位、温度计或股债利差。开网深度由网格结构与用户资金决定。

2. **第 2 步：定参数（三层复合网格与步长模式）**
   - 确认初始资金（默认 50% 基础底仓 + 50% 网格流动现金金池）；
   - 设置基准价格锚点（最新收盘市价或手动指定自有持仓成本均价）；
   - 选用步长模式：日常高频套利选择 **ATR 动态自适应（默认）**；长周期大波段守株待兔选择 **E大原版经典大步长（5%/15%/30%）**。

3. **第 3 步：测极限（行情压力测试沙盘）**
   - 拖动 0% ~ -60% 平滑跌幅滑块，实时观察资金消耗速度与子弹耗尽临界点；
   - 动态掌握水淹满仓状态与绝地脱困标尺（量化证明持仓均价摊薄后少涨 10%~30% 即可保本解套）。

4. **第 4 步：验回测（5 年跨牛熊历史数据检验）**
   - 选择 90天/180天/1年/2年/3年/5年 回测周期；
   - 运行基于 `GridSlot` 槽位状态机的全量配对撮合，查阅 Alpha 超额收益曲线、最大回撤与三色彩虹利润拆解；
   - 随时将参数与结果归档至本地 SQLite 数据库，支持历史复盘对比。

同一赛道里哪只更适合做网格，看首页或档案库旁的 **网格适合度榜**，不要用个人回测档案互相比较。榜用锁定协议：本金 30,000 元、利润池留股、最近 1,825 个日历日、默认 ATR 乘数、默认 5% / 15% / 30% 自定义网格。一只标的一行，ATR 自适应与自定义网格各一列。默认按 **年化做 T 现金收益率**（做 T 纯现金利润 / 30,000 × 365 / 实际日历天数）从高到低排，名次只在所选赛道内计算。年化总收益只作辅列，并标明含底仓涨跌。行情不足、成交过稀或回撤超线的不进主榜。协议结果写入独立榜表，不进入个人回测档案。

5. **第 5 步：抄挂单（一键复制落地券商）**
   - 查看 20 档多轨合并买卖挂单表；
   - 点击一键复制委托价格与委托股数，直接录入华宝智投、同花顺、银河玖乐等券商网格条件单。

## 🏗️ 系统技术架构

### 后端架构
- **核心框架**：Python 3.10+ / Flask 3.0+
- **数据引擎**：AkShare / TuShare 行情与 K 线
- **存储库**：`BacktestRepository`（本地 SQLite3 WAL 模式策略档案库）
- **核心算法模块**：
  - `SuitabilityAnalyzer`：标的 100 分制 4 维量化体检引擎
  - `CompositeGridCalculator`：立体三层多轨资金分配、万 1 最低 0.2 元费率与阶梯归并
  - `GridBacktestEngine`：基于 `GridSlot`（IDLE/HOLDING 二值状态机）的 A 股 T+1 历史回测撮合引擎
  - `GridOptimizer`：基于 Welles Wilder 14 日 ATR 自适应步长与 E大经典双模式派生

### 前端架构
- **核心框架**：React 18 + Vite 5 + Tailwind CSS 3.4 + Lucide React 图标
- **路由与状态**：React Router 6 + 全量量化参数 URL 双向序列化同步引擎（`url.js`）
- **沙盘演算**：纯函数式客户端毫秒级演算（`< 16ms`，60fps 拖拽无感延迟）
- **图表系统**：原生轻量 SVG 矢量图表，零第三方图表包依赖，秒开无卡顿

## 💬 常见问题与实战心法 (FAQ)

**Q：什么样的标的最适合跑这套立体复合网格？**
> **A**：必须满足“长期不会死、向下有坚实估值底、波动率足够充沛”的指数 ETF（如红利低波、沪深300、中证500、恒生科技、半导体芯片、医药医疗等）。严禁使用无业绩支撑的个股或衰退行业。系统首页的【4维量化体检】会根据波动率黄金区间（15%~45%）和震荡指数（ADX < 20）进行严格把关，一票否决不适宜标的。

**Q：遇到单边大跌被套在网格里了怎么办？**
> **A**：首先，系统的大中小网配比与倒金字塔加码机制保证了深水区有充足的流动资金；其次，若跌破大网进入“超深水淹满仓状态”，小网熔断哨兵会自动触发停止盲目开仓，此时持仓成本已被大幅摊薄。策略进入“守株待兔”休眠期，静待标的估值修复，切忌在底部恐慌割肉。

**Q：模式 B（留存股票）相比模式 A（留存现金）有什么长远优势？**
> **A**：模式 A 每次做 T 赚取的是现金，遇到单边大牛市时网格筹码会被快速抛光，导致错失后续翻倍行情；模式 B 则将单笔做 T 差价全部在 0 成本利润池中蓄积，每攒满 100 股自动转增为永久免费持仓。手握 0 成本筹码，不仅持有体验毫无心理负担，还能充分享受长牛主升浪的复利红利。
